اسحاقزاده حساب — اصلاح شوې نسخه

دا نسخه لا په انلاین لینک نه ده پورته شوې؛ GitHub د مستقیم خپرولو اجازه ورنه کړه.

د پورته کولو طریقه:
۱. په اوسني حساب کې تنظیمات → بیک‌اپ ډاونلوډ ووهه.
۲. ZIP خلاص کړه.
۳. په خپل GitHub کې nk6341350-cloud/ishaqzada-hisab خلاص کړه.
۴. Add file → Upload files ووهه.
۵. د ZIP دننه فایلونه مستقیم د main څانګې اصلي ځای ته پورته کړه، په بله فولډر کې نه؛ index.html، app.js او README.txt بدل کړه او نوي bill.js، bill-arabic.woff او FONT-LICENSE.txt هم ورسره پورته کړه.
۶. Commit changes ووهه او د GitHub Pages خپرېدو ته انتظار وباسه.
۷. هماغه پخوانی لینک په هماغه براوزر کې بیا تازه کړه. د براوزر معلومات مه پاکوه.

د کس حساب:
مشتریان → حاجي محمد قاسم → د حساب تفصیل → جنسونه / پیسې.
د جنس اخیستلو یا ورکولو ډول وټاکه. د «بل جنس ورزیات کړه» په وهلو هر څو جنسونه ثبتولای شې. وروسته بیا هم همدغه کس انتخاب کړه. ټولې نېټې، جنسونه او ورکړې یې په یوه حساب کې جمع کېږي.
«ما کس ته پیسې ورکړې» او «ما له کس څخه پیسې ترلاسه کړې» د نغدو پیسو لپاره دي.

بیل:
د کس حساب → بشپړ بیل → د واټساپ لپاره PDF بیل.
چې تیار شو، «بیل په واټساپ شریک کړه» ووهه او واټساپ او خپل مخاطب انتخاب کړه.
که موبایل فایل شریکول نه مني، PDF خوندي کړه او واټساپ کې یې د سند په توګه ضمیمه کړه.
که حساب اوږد وي، ټولې پاڼې په یوه PDF فایل کې وي.

پخواني حسابونه:
د زېرمه کولو پخوانی نوم نه دی بدل شوی؛ په هماغه موبایل او براوزر کې معلومات پاتې کېږي.
معلومات یوازې په همدې براوزر کې دي؛ په منظم ډول JSON بیک‌اپ وساته.
د پخوانۍ معاملې یا د کس معلومات د «سمون» تڼۍ له لارې اصلاح کېږي.
